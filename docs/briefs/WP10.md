## The analyst skill (`skill/SKILL.md`)

Write the Claude Code skill that an analyst session follows to run one scan
cycle. Frontmatter with `name: gwylio-scan` and a one-paragraph description.
Then the numbered workflow, each step naming the exact command:

0. `gwylio datecheck`: for every finding, verify against the world (web
   search), never assume; corrections go into the next submission's `updates`
   or `verifications`, never into the database by hand.
1. `gwylio collect` (and which disciplines are available without a Brave key).
2. Read the newest candidates file; for every candidate open the source page
   and judge against `docs/RUBRIC.md`; write
   `data/submissions/<run_id>__<n>.json` with a disposition for EVERY
   candidate, promotions graded with reliability from the source and
   credibility you judge, assessments with directions, the optimism and
   mainstream guard questions answered in `method_note`.
3. `gwylio ingest <file>`; fix validation errors in the file, never in code.
4. `gwylio sweep`.
5. `gwylio product --level operational --period <YYYY-MM>`; once a year
   `--level strategic`.
6. `gwylio export`, `gwylio publish`.
7. Commit: the candidates file, the submission, the exports, the snapshot,
   the products, with a dated message; never commit `data/gwylio.sqlite`.
8. Report in chat: what moved, what faded, what is quiet, what is a blind
   spot, the method note.

Include the submission file skeleton (valid JSON with placeholder values
drawn from `skill/REFERENCE.md`), the three bias guard questions, and the
rule that the collector never scores and the analyst never edits the
database. A backend test asserts that every CLI verb named in SKILL.md exists
on the Typer app and that every existing verb is named at least once.

## Hosting

- `firebase.json` at the project root: hosting `public: "frontend/build"`,
  `cleanUrls: true`, `trailingSlash: false`, `ignore` for firebase files,
  headers setting `Cache-Control` for `/data/**` to `no-cache` and for hashed
  `_app/immutable/**` to one year. No `.firebaserc` (the project id is the
  owner's); document `firebase use --add`.
- `docs/DEPLOY.md`: install the Firebase CLI, `firebase login`, `firebase
  use --add`, `make publish && pnpm -C frontend build && firebase deploy
  --only hosting`; a note that the site is public by URL and that Firebase
  Authentication is the planned answer (ADR 0004: write it, status
  "proposed", with the options: Firebase Auth with an allow list; Cloud Run
  behind Identity-Aware Proxy; keep public and publish nothing sensitive).

  line if the `firebase` command is missing.
